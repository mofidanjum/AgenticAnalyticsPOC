# Stage 6: Streamlit Web App — Quick Start Guide

Beautiful web interface for your analytics agent. No terminal needed!

---

## 🚀 Quick Start (5 minutes)

### Step 1: Install Dependencies
```powershell
cd C:\Users\Sarah\projects\agentic-data-pipeline\stages\stage_6

# Install packages
pip install -r requirements.txt
```

### Step 2: Set API Key
```powershell
# Set environment variable
$env:ANTHROPIC_API_KEY = "sk-ant-your-actual-key-here"
```

### Step 3: Run the App
```powershell
# Start Streamlit server
streamlit run app.py
```

### Step 4: Open Browser
Click the link or open `http://localhost:8501`
